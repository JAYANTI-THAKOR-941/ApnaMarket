# ApnaMarket — Storefront

Static storefront prototype with product, product detail, services, about and contact pages.

## Project structure

`index.html`, `product.html`, `productDetails.html`, `style.css`

## Getting started

```bash
git clone https://github.com/JAYANTI-THAKOR-941/ApnaMarket.git
cd ApnaMarket
```

Open `index.html` in a browser or serve the project with a local static web server.
